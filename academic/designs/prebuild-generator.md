# Pre-Build Spec Generator — Architecture

## What it is

A Swift executable that runs before compilation. Reads TLASpec files, generates
composed specs. The generated file is regular Swift with `@TLAActor` annotations.
The existing macro verifies the generated code.

```
swift run compose    →    Sources/Generated/Compositions.swift    →    swift build
                         (generated, @TLAActor verified)              (compile + prove)
```

## What it guarantees

1. Child specs define their public API (actions, variables, invariants)
2. Parent spec declares `#importSpec("Child")` and cross-actor guards
3. Generator resolves child APIs, generates parent code that calls child methods
4. `@TLAActor` macro verifies the generated parent compiles with invariants intact
5. Two proofs: generator proves interop, macro proves invariants

## How it works

### Step 1: Parse child specs

```
Input: Sources/SwiftTLAVerified/Capture.swift
Output: SpecInfo(name: "Capture", actions: [...], variables: [...], invariants: [...])
```

Generator parses each `@TLAActor` file's `static var spec: TLASpec` getter.
Extracts the DSL calls: `Variable(...)`, `Action(...)`, `Invariant(...)`.

### Step 2: Resolve parent imports

```
Input: Sources/SwiftTLAVerified/MediaContract.swift
        #importSpec("Capture")
        #importSpec("Writer")
        #importSpec("Player")
        
Output: Resolves each import → SpecInfo for that child
```

### Step 3: Generate composed spec

For each child imported:
- Copy `Variable(...)` declarations into parent spec
- Copy `Action(...)` declarations into parent spec
- Copy `Invariant(...)` declarations into parent spec

For cross-actor guards:
- Keep parent's `Action(...)` overrides (they replace child actions with same name)
- Keep parent's `Invariant(...)` additions

### Step 4: Generate coordinator protocol + methods

For each parent action, generate a method that:
- Checks cross-actor guard (from parent spec's action body)
- Calls child's generated method (from child spec's action)

```swift
// Generated from #importSpec("Capture") + Action("cStop") override
func cStop() {
    guard _state.cPhase == 2 || _state.cPhase == 3 else { return }
    guard _state.wPhase != 2 && _state.wPhase != 3 else { return }
    _state = _apply(.cStop)    // own state transition
    capture.stop()              // child's generated method
}

// Generated from #importSpec("Writer") + Action("wStart") override
func wStart() {
    guard _state.wPhase == 1 && _state.cPhase == 2 else { return }
    _state = _apply(.wStart)   // own state transition
    writer.start()              // child's generated method
}
```

## Generated file example

```swift
// Sources/Generated/Compositions.swift — DO NOT EDIT, generated by compose

import SwiftTLA
import SwiftTLAMacros

@TLAActor
public actor MediaContract {
    public let capture: Media.Capture
    public let writer: Media.Writer
    public let player: Media.Player

    public static var spec: TLASpec {
        TLASpec("MediaContract") {
            // ── Imported from Capture ──
            let cPhase = Var<Int>("cPhase"); Variable(cPhase, 0)
            Action("cConfigure")  { cPhase == 0 && cPhase.becomes(1) }
            Action("cStart")      { cPhase == 1 && cPhase.becomes(2) }
            Action("cResume")     { cPhase == 3 && cPhase.becomes(2) }
            // ── Imported from Writer ──
            let wPhase = Var<Int>("wPhase"); Variable(wPhase, 0)
            // ... all Writer actions ...
            // ── Imported from Player ──
            let pPhase = Var<Int>("pPhase"); Variable(pPhase, 0)
            // ... all Player actions ...

            // ── Cross-actor overrides ──
            Action("cStop")     { (cPhase == 2 || cPhase == 3) && (wPhase != 2 && wPhase != 3) && cPhase.becomes(0) }
            Action("cInterrupt") { cPhase == 2 && (wPhase != 2 && wPhase != 3) && cPhase.becomes(3) }
            Action("wStart")     { wPhase == 1 && cPhase == 2 && wPhase.becomes(2) }
            Action("pPlay")      { (pPhase == 2 || pPhase == 4) && wPhase == 4 && pPhase.becomes(3) }

            Invariant("writerRequiresCapture") { (wPhase != 2 && wPhase != 3) || (cPhase == 2) }
            Invariant("playerRequiresWriter")  { (pPhase != 3) || (wPhase == 4) }
        }
    }
}
```

## Why this is safe

1. Generated code is deterministic — same input always produces same output
2. Generated code is regular Swift — `@TLAActor` macro verifies it at compile time
3. Generated code is in source control — diffable, reviewable
4. Generator doesn't need to be correct — `@TLAActor` catches invariant violations
5. Two layers of proof: generator + macro, not one
