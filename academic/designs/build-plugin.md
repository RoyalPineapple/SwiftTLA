# Generated MediaContract — Full Interface

## What the developer writes (parent spec)

```swift
// Sources/MediaContract.swift
@TLAActor
public actor MediaContract {
    let capture = Media.Capture()
    let writer = Media.Writer(...)
    let player = Media.Player(...)

    public static var spec: TLASpec {
        TLASpec("MediaContract") {
            #importSpec("Capture")
            #importSpec("Writer")
            #importSpec("Player")

            Action("cStop")  { ... cross-actor guard ... }
            Action("wStart")  { ... cross-actor guard ... }

            Invariant("writerRequiresCapture") { ... }
        }
    }
}
```

## What the build plugin generates

Plugin copies child actions + applies cross-actor overrides → `@TLAActor` verifies.
Plugin ALSO generates coordinator methods that wire children together.

```swift
// Generated by ComposePlugin
extension MediaContract {
    // ── Coordinator methods (generated from cross-actor actions) ──

    public func configure(device: AVCaptureDevice, outputURL: URL) async throws {
        try capture.configure(device: device)
        cConfigure()                          // own state transition (from Capture)
        try await writer.start()
        wConfigure()                          // own state transition (from Writer)
        try await player.load()
        pLoad(); pReady()                     // own state transitions (from Player)
    }

    public func record() async throws {
        try await capture.start()
        cStart()                              // own state transition
        // wStart has cross-actor guard: wPhase==1 && cPhase==2
        wStart()                              // proven by @TLAActor
    }

    public func stopRecording() async throws {
        try await writer.finish()
        wFinish()
        // cStop has cross-actor guard: (wPhase!=2 && wPhase!=3)
        capture.stop()
        cStop()                               // proven by @TLAActor
    }

    public func play() {
        // pPlay has cross-actor guard: wPhase==4
        pPlay()                               // proven by @TLAActor
        player.play()
    }
}
```

## What the developer sees

```swift
import SwiftTLAVerified

let pipeline = MediaContract(outputURL: url)
try await pipeline.configure(device: camera, outputURL: url)
try await pipeline.record()         // 5 seconds of video
try await pipeline.stopRecording()
pipeline.play()                      // previews the recorded file
```

## How the wiring works

1. `MediaContract` holds `Capture`, `Writer`, `Player` instances (AVFoundation hardware)
2. `@TLAActor` spec tracks three phases (`cPhase`, `wPhase`, `pPhase`)
3. Generated coordinator methods call:
   - Child actor methods (hardware: `capture.start()`, `writer.finish()`)
   - Own state transitions (spec: `cStart()`, `wFinish()`)
   - Cross-actor guards built into action bodies (`wPhase==1 && cPhase==2`)
4. `@TLAActor` proves invariants at compile time
5. Runtime: guards enforced by generated methods + `@TLAActor` validation

Five lines of developer code.  Hardware, state machine, cross-actor guards —
all wired by the plugin.  Proven at compile time.
