# Parser-builder portable fixture

This directory is an exportable `SwiftTLA-Validation` corpus unit. A caller supplies only a project root, this manifest, a fresh output directory below that root, and distinct gate, fixture, and comparison UUIDs. It must invoke the public `PublicWorkflowParserBuilderAdapter.run(manifestURL:projectRoot:outputDirectory:correlation:)` API. The CLI exposes this unchanged through `tlc-validate public-workflow parser-builder run`.

The manifests use only project-relative paths and SHA-256 pins. Applicable implementation identities (`Package.resolved`, `Package.swift`, and the adapter source) are pinned in `toolchain.dependencies`; TLC, Java, and a bridge binary are explicitly non-applicable with a retained reason pin. The runner rejects absolute/out-of-root paths, symlink escapes, changed source/configuration/provenance/toolchain pins, and observations whose canonical generated bytes differ from the retained bytes. `Mismatch/manifest.json` is the permanent fully pinned negative control and must retain `difference` / `observationDifference`, never success. `run.json` is diagnostic until retained and attested by hosted CI.
