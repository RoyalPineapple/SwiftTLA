# SwiftTLA

Provably correct state machines from TLA+ specifications, in Swift.

## Architecture

Every component is independently verified. The pipeline:

```
Swift DSL  ──► @TLAModel macro ──► ModelChecker ──► StateMachine generator
    │                │                    │                  │
    │           SpecParser            CheckerController    Generator tests
    │           (9 parser tests)     (11 self-proof)      (5 tests)
    │                │                    │                  │
    └────────────────┴────────────────────┴──────────────────┘
                              │
                         .tlaModule ←── SANY validates
                         .swiftSource ←── round-trip tests
```

## Usage

```swift
import SwiftTLA
import SwiftTLAMacros

@TLAModel
public struct HourClock {
    static var spec: TLASpec {
        TLASpec("HourClock") {
            let hr = Var<Int>("hr", value: 1)
            Variable(hr, 1)
            Action("Tick") {
                (hr != 12) && hr.becomes(hr + 1) ||
                (hr == 12) && hr.becomes(1)
            }
            Invariant("Valid") { hr >= 1 && hr <= 12 }
        }
    }
}

// Generated by macro:
let machine = HourClock.StateMachine.initial  // hr=1
machine.availableTransitions                   // [.tick]
machine.apply(.tick)                          // hr→2
```
